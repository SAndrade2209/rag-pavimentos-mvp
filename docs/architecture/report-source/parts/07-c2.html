6. C2 Containers

Key points
  • Five containers. One deployable API application (modular monolith) holds the platform logic (Section 10). Technologies are candidates, not chosen; all run on any cloud provider or on premises.
  • The language model receives no result rows and has no database access (ADR 6). All client data sit in one database, isolated by client with row-level security (ADR 3; ADR 7).
