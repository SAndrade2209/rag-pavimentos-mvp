5. C1 System context

Key points
  • One system for all clients. Everyone signs in through the identity service (UC-07); what each person may do is decided inside the platform, per project.
  • PCI data enter by upload and, for the funding agency only, by an automatic connection (dashed: method pending, ADR 4). A hosted language model would appear here as an external system (note in c2-containers.puml).
