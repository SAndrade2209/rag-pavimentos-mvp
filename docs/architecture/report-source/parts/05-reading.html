Part II. Context and containers

4. How to read the diagrams

The architecture is described with the C4 model at three levels (ADR 1). Each level zooms into one box of the level above.

LevelShowsAudienceSection
C1 System contextThe platform as one box, the people who use it and the external systems it depends on.Everyone, including non-technical stakeholders5
C2 ContainersThe applications and data stores inside the platform, with candidate technologies and the protocols between them.Technical team6
C3 ComponentsThe modules and components inside the API application, in three focused views.Technical team10
Level 4 (code)Not produced; generated from the code if ever needed.

The diagrams are written as code in PlantUML with the C4-PlantUML library, kept in Git and reviewed in pull requests. This report shows the styled copies in docs/architecture/c4/styled/. They have the same elements and relationships as the diagrams in docs/architecture/c4/, which stay the source of truth, with shorter text, colors and icons. The tables in this report use the full descriptions from the source diagrams.
