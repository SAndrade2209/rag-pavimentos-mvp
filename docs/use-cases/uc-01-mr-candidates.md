# UC-01 Identify M&R candidate sections

## Actor
- Primary: pavement management engineer; district/maintenance staff; airport pavement management staff.
- Secondary: Continuum consultant.

## Goal
List the sections in poor condition in the latest survey to build the maintenance and rehabilitation (M&R) work program.

## Example question
"Which sections had a PCI below 55 in the latest survey?"

The threshold (55) is an example given by the user in the question, not a recommended value.

## Data required
- Section
- PCI
- Year

## Expected result
- A short answer with the number of sections below the threshold.
- A table of section, survey year and PCI, sorted from lowest PCI, with the source rows. Downloadable.
- The answer states the PCI threshold and the survey year used.
- If the question gives no threshold and none is configured, the system asks the user for one before answering.

## Open items
- PCI threshold source: per-client setting, stated by the user, or both. Not decided.
